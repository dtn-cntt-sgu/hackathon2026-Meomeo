## 2. Sau khi Claude mở PR (việc của Thiện)

1. Mở link PR Claude in ra. Chờ CI (`ci`) xanh. CI đỏ thì dán lỗi CI cho Claude sửa trên cùng nhánh rồi push lại.
2. Bấm **Merge pull request ⇒ Create a merge commit** (không Squash, không Rebase). Merge xong, workflow `deploy` tự chạy.
3. Xem tab Actions: chờ `smoke` xanh, bấm **Review deployments ⇒ Approve** cho `production`. Thử tay theo **Tiêu chí đạt**.
4. Workflow đỏ thì dán log lỗi (`gh run view --log-failed`) cho Claude sửa trên nhánh mới `thien/th-19-fix`, lặp lại từ bước 1.
5. Nhắn nhóm: "pipeline đã chạy". Từ đây mỗi lần merge vào `main` là staging tự cập nhật.
