## 1. Prompt dán cho Codex

Mở Codex trong thư mục repo thi (đã có `docs/`), dán nguyên khối dưới đây. Codex tự tạo nhánh `quy/qu-02`, đọc tài liệu, code, kiểm, commit, push và mở PR. Việc của bạn: trả lời khi Codex hỏi, cho phép chạy lệnh git/gh khi được hỏi, rồi làm Mục 2.

**Nếu Codex không chạy được `git push` hoặc `gh pr create`** (bị chặn mạng hay quyền), Quý tự chạy 2 lệnh ở BƯỚC 5 trong terminal của mình rồi dán link PR cho Codex biết.

```text

Thư mục docs/ là tài liệu của đội, đã có trên main: không sửa, không xóa, không add file nào trong docs/. Làm lần lượt 6 bước dưới đây, xong bước nào báo ngắn bước đó.

BƯỚC 0 — Nhánh: chạy `git checkout main` rồi `git pull`, sau đó `git checkout -b quy/qu-02` (nếu nhánh đã có thì `git checkout quy/qu-02` rồi `git merge main`). Chạy `git status`: nếu thấy có thay đổi trong thư mục docs/ thì DỪNG và báo tôi, không commit thay đổi đó.

BƯỚC 1 — Đọc: đọc hết file `docs/ke-hoach-thi/phieu/quy/QU-02.md` (nhất là mục Yêu cầu, Bẫy đã biết, Tiêu chí đạt), phần "Luật chung cho mọi phiếu" ở đầu `docs/ke-hoach-thi/02_PHIEU_THIEN.md`. BƯỚC 2 — Code: Hãy đọc kỹ file `docs/spec/30_UI.md` (Mục 2, Mục 11), `docs/spec/00_QUYET_DINH.md` (D-81, D-35), `docs/spec/01_KIEN_TRUC_VA_LUONG.md` (Mục 9) và `docs/spec/21_AI_KIEM_VA_DUYET.md` (Mục 11) trước khi viết code. BƯỚC 4 — Commit: trước khi commit chạy `git fetch origin` rồi `git merge origin/main`, có xung đột thì gỡ và chạy lại 3 lệnh kiểm. Nếu khoảng 30 phút vẫn chưa xong, hoặc gặp lỗi quyền, lỗi đăng nhập GitHub (`gh auth status`), xung đột không tự gỡ được, hãy dừng và báo tôi đang kẹt ở bước nào.
```

## 2. Sau khi Codex mở PR (việc của Quý)

1. Mở link PR Codex in ra. Chờ CI (`ci`) xanh. CI đỏ thì dán lỗi CI cho Codex sửa trên cùng nhánh rồi push lại.
2. Thử tay theo mục **Tiêu chí đạt** bên dưới.
3. Bấm **Merge pull request ⇒ Create a merge commit** (không Squash, không Rebase).
4. Nhắn nhóm: "đã merge QU-02". Người đang làm phiếu khác tự `git pull`.
