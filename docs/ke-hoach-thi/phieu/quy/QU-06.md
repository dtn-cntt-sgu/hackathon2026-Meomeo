## 2. Sau khi Codex mở PR (việc của Quý)

1. Mở link PR Codex in ra. Chờ CI (`ci`) xanh. CI đỏ thì dán lỗi CI cho Codex sửa trên cùng nhánh rồi push lại.
2. Thử tay theo mục **Tiêu chí đạt** bên dưới.
3. Bấm **Merge pull request ⇒ Create a merge commit** (không Squash, không Rebase).
4. Nhắn nhóm: "đã merge QU-06". Người đang làm phiếu khác tự `git pull`.
