  - `bkt-engine.ts`: `getDecayedMastery(state, now): number`, `tierOf(p): LearnerTier`, `overallTier(skills, now): LearnerTier`, `isDecaying(state, now): boolean`, `outcomeOf(isPassed: boolean, attemptsUsed: number): NodeOutcome`, `updateSkill(skill, state, outcome, now): CognitiveSkillState`, `computeSkillChange(skill, state, outcome, now): { next: CognitiveSkillState; change: SkillChange }`.

  - `derive.ts`: `aiTitleOf(nodeId, overview)`, `displayTitle(node, overview): string`, `deriveNodeStates(skeleton: GraphSkeletonNode[], progressRows): Record<string, DerivedNodeState>`.
  - `similarity.ts`: `validateAnswerLength(a: string): "ERR_ANSWER_TOO_SHORT" | "ERR_ANSWER_TOO_LONG" | null` (đếm ký tự sau khi bỏ khoảng trắng, dùng `CONFIG.ANSWER_MIN_CHARS` = 5 đã nới ở Q-05), `levenshtein(a: string[], b: string[]): number`, `similarity(a, b): number` (1 − Levenshtein / độ dài lớn nhất).
  - `moderation.ts`: `BAD_WORDS`, `wordRe(k): RegExp` (khớp trọn từ, Unicode), `hasInappropriateWords(text): boolean` (chuẩn hóa NFC trước), `maskSensitive(text): string` (che email, SĐT VN, CCCD, từ xấu bằng `***`, giữ nguyên số dòng).
