# SimpliFey

Học code từ repo thật theo bản đồ bài học do code dựng và AI giải thích.

## Tự cài đặt

Yêu cầu môi trường: Node.js 22.

1. Cài đặt các gói phụ thuộc:
```bash
npm ci
```

2. Cấu hình biến môi trường:
Chép `.env.example` thành `.env.local` rồi điền giá trị.

3. Khởi chạy ứng dụng:
```bash
npm run dev
```

## Lệnh kiểm

- Kiểm tra kiểu (typecheck):
```bash
npm run typecheck
```

- Kiểm tra mã nguồn (lint):
```bash
npm run lint
```

- Chạy kiểm thử (test):
```bash
npm test
```
